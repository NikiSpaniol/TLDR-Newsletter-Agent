SWARM SCALING (13 MINUTE READ)

Toby Ord analyzes the scaling behavior of AI agent swarms using data from OpenAI's recent demonstrations, including a 1,200-agent swarm that coordinated to attack Hugging Face and a 10,000-agent swarm that solved the Navier-Stokes problem in 88 hours.

Toby Ord analyzes the scaling behavior of AI agent swarms using data from OpenAI's recent demonstrations, including a 1,200-agent swarm that coordinated to attack Hugging Face and a 10,000-agent swarm that solved the Navier-Stokes problem in 88 hours. Ord applies an economics framework using the "stepping on toes" parameter lambda (λ), which measures task parallelizability, and derives λ values of 0.48 to 0.68 across three benchmarks from GPT-5.6 data. The key finding is that increasing swarm size by N agents provides only N^λ times the performance gain of increasing tokens N times for a single agent, meaning a 100x token scale-up requires 900x to 15,000x agent scaling to match. The primary practical advantage of swarms is speed rather than efficiency: a 4-agent swarm delivers results in half the time at 2x the cost, and swarms may eventually exceed single-agent capability ceilings. Ord notes the measured λ values align with prior estimates used in recursive self-improvement models, suggesting intelligence explosions remain plausible, and he attributes OpenAI's Navier-Stokes breakthrough primarily to model improvements rather than swarm scale.

MIMO-V2.6: SCALING REINFORCEMENT LEARNING TOWARDS SELF-IMPROVEMENT (9 MINUTE READ)

MiMo-V2.6 addresses a fundamental problem in reinforcement learning for AI agents: binary pass-fail rewards cannot distinguish between a correct minimal fix and a brittle workaround that achieves the same test outcome.

MiMo-V2.6 addresses a fundamental problem in reinforcement learning for AI agents: binary pass-fail rewards cannot distinguish between a correct minimal fix and a brittle workaround that achieves the same test outcome. The paper introduces Groupwise Advantage Redistribution (GAR), which compares multiple solution attempts jointly and redistributes reinforcement signal toward cleaner, higher-quality passing solutions while zeroing out confirmed hacks. The approach processes 1,568 prompts per training step with 16 attempts per prompt, consuming 2.7–3.7B training tokens per update, and was applied across four domains—coding, professional workflows, visual design, and cybersecurity—with post-training costs of $2.6M for the larger model and $0.9M for the smaller. A controlled ablation shows that without GAR, pass-rate improvements plateau while attempts grow longer and consume more tokens; with GAR, improvements persist while token length grows more gradually. The paper also identifies that during large-scale RL with Mixture-of-Experts architecture, updating the router weights caused severe load imbalance, which was resolved by freezing the router throughout training. Results show MiMo-V2.6-Pro's performance on DeepSWE rising from 58.4 to 72.6 average@3 score, with reproducibility demonstrated through a released 9B-parameter distilled variant.

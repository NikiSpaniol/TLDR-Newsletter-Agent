MUSE SPARK OPEN (4 MINUTE READ)

Meta released Muse Spark Open, an 816-billion-parameter open-weight AI model with 42 billion active parameters and a 1-million-token context window designed for coding and agentic tasks.

Meta released Muse Spark Open, an 816-billion-parameter open-weight AI model with 42 billion active parameters and a 1-million-token context window designed for coding and agentic tasks. The model is optimized to run on consumer hardware for the first time, specifically on two Apple M5 Ultra Mac Studios using the MLX framework, leveraging the chip's unified memory architecture to create what functions as a single supercomputer with a terabyte of memory. The model is available immediately through multiple platforms including Hugging Face, cloud providers like Google Cloud and AWS SageMaker, and inference partners such as Together AI and Groq, with support across multiple inference engines and hardware optimizations for AMD, Apple, Intel, and NVIDIA processors. Meta demonstrated real-world capabilities including autonomous iOS development work and video editing tasks performed entirely on-device, and released the weights under a limited commercial license allowing many developers free use. The release includes additional safety post-training measures and meets Meta's Superintelligence Scaling Framework thresholds for responsible deployment.
